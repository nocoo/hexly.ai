# Rhino presentation icons

The exact approved family foreground is composed over its independently authored savanna grasses background. No extra image-model call, crop, recoloring or placement change.

Hexly cards use rounded WebP directly without another mask; platform icons use opaque square PNG. Browser and source-product navigation marks remain transparent foregrounds. The ICO contains six transparent PNG frames. The continuous-corner mask is an authored approximation, not an official Apple asset.

Generation rights follow the archived Azure output; authored support geometry follows the Hexly MIT license. Source-product UI palettes remain independent.
