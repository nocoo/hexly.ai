# Full-square material coverage experiment

The owner found the 21-project material batch too concentrated on the right.
Test three physical-material motifs before any wider rollout: Coffee porcelain
turning arcs, Matrix routing grain and GeekHub book-cloth folds. Each receives
one native 1024-square light/dark pair using the approved Flare deployment.

The revised brief distributes visible worked relief across all four quadrants
and the middle. It targets a 90-95% width/height envelope and roughly 65-75%
worked area, with small scattered breathing spaces instead of an empty half.
Those are prompt targets, not measured results. Preserve the shared paper
palette, shallow relief and fine internal detail. The original icon is unchanged.

Review: <https://index.dev.hexly.ai/.video-work/material-coverage/review.html>

The review compares each old surface with its new original, plus botanical
palette/detail references. Original PNGs remain untouched and linked directly.
Local JPEG inspection copies and review HTML live only in `.video-work/`.

```sh
node artwork/brand-textures/2026-09-27-material-coverage/review.mjs
python3 artwork/brand-textures/2026-09-27-materials/generate.py --inventory docs/brand-textures/2026-09-27-material-coverage/inventory.json --attempt 1
```

The generator command above is read-only. Generation uses the unchanged Workflow
helper via the recorded material transport and an explicit `--generate` flag.
Successful calls are never repeated after a conversation interruption.

[Inventory](inventory.json) preserves the exact owner correction, selected
scope, identity evidence, prior candidates and new prompts. All new originals
remain pending exact-byte owner acceptance. Broader rollout, pack export,
catalogue adoption, icon composition, R2 and publication await that checkpoint.
