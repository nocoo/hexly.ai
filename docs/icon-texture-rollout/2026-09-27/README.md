# Approved textured icon rollout

The owner's nine-project review was approved for all 60 non-archived Hexly
catalogue projects and a patch release to v1.1.2. Authorization and exact source
hashes are retained beside this record. No image-generation calls were made.

The deterministic composer retains each native foreground canvas and uses the
approved light texture at 70% opacity on #f0f0e9. Native opaque foreground RGB
matches the source; all nine pilot outputs match the approved decoded pixels.
The continuous-corner approximation is the approved study outline, not an
extracted Apple asset. iOS and Apple touch masters are opaque square exports.
The 900/920/960 px masters remain native; their 1024 px variants are upscales.

Independent icon packages are selected by `Project.presentationIcon`. They cover
site navigation, cards, the logo wall, project review and sizes, status, live video
previews, discovery images, API presentation choices and icon downloads. Original
identity bytes, transparent-mark downloads, historical brand/hero/social artwork,
source adoption and all 21 archived project entries remain preserved.

`composition.json` records 60 native pixel inspections and all immutable output
hashes. Publication results verify 685 texture objects and 1,560 icon objects.
`initial-deployment.json` records the successful v1.1.2 CI and deployment at
`b1f396018b8f43a21091623e8bcc68156eeafe70`. Production acceptance passed all 60
project APIs, 120 desktop/mobile theme cases and nine actual PNG downloads.

The final read-only retirement audit extends the material-only list to all
superseded independent packs of active projects: 27 packs, including nine bird
versions, plus the already superseded material experiments. The exact allowlist
contains 649 local paths and 595 R2 keys, with no surviving aliases or current
page/profile references. The authenticated origin audit confirmed 540 existing
objects and 55 absent experimental source keys. All 540 existing objects were
deleted after production acceptance, freeing 107,238,154 bytes; every retired key
was verified absent at the R2 origin. Cached CDN responses are not deletion proof.

The cleanup removed 649 local files totaling 291,913,660 bytes and their active
inventory aliases. The remaining inventory has 13,824 paths and 12,393 objects.
`retirement-result.json`, `retirement-preflight.json`, `docs/assets/retired.json`
and the append-only deletion journal retain the exact evidence. The inventory
reader and builder reject retired paths and keys, so the temporary CI hydration
exclusion is removed. Embedded textures in the Pi Agent Policy, Diorama Journey
and Zeppelin identity kits remain protected dependencies.

The release sequence creates the immutable v1.1.2 tag from the cleaned inventory
after final CI and deployment verification; the initial deployment was deliberately
left untagged. See `release-sequence.json`.
