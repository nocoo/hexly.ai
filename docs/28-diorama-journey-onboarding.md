## Product evidence and identity

The skill creates narrated miniature 3D stories from source material. A recurring
element joins chapters on one timeline, producing a film, chapter MP4s, subtitles
and PPTX/PDF/ODP slides with speaker notes. The original example follows one
amber lantern through a gateway, lookout, workshop, bridge and garden.

Study `2026-09-17-01 / 01` uses that example as its primary reference. The approved
Sunburst image contains a cream gateway, terracotta cap, sage island and model
trees, stone path, golden ring and amber lantern. Continuous physical materials
follow the tool direction. The former README emoji is not a previous independent
Logo, so `family.previous` is null.
