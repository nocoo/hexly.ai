# Pi Agent Policy onboarding

Pi Agent Policy is a user-level Pi extension for declarative tool rules and
bounded recovery. Its default repair allowance is shared across policy repair
and eligible terminal continuation for one original user input. It is neither
an OS/network sandbox nor a guarantee of exactly-once tool execution.

The owner requested a physical tool identity after rejecting the animal route,
then approved the exact study 03 image with “生成的图片效果不错，可以继续下后面的流程”.
The catalogue adds one Tools entry at the end. There is no independent website
and therefore no fabricated `/api/live` target. The source repository remains
private; no private source-code or source-document snapshot is published here.

## Brand kit and delivery

The kit contains exact official/campaign foreground bytes, transparent PNG
sizes and six-entry ICO, real Space Grotesk 600 outlined wordmarks with full
descenders, light/dark raster lockups, presentation icons, independent 2400×960
wide and 1024² mobile Hero layouts, repeatable light/dark contact textures,
tokens, rights, exact generation records, a specimen page and file manifest.

The foreground was generated and owner-approved. Kit assembly and Hero layout
make no additional image-model call. Heroes are authored full-canvas composites,
not native GPT Image outputs or replacements for the adopted project Logo.
Hexly surface colors and fonts apply to Hexly archives/campaigns only; no product
UI palette is claimed. Generated artwork rights remain subject to provider and
reference rights; MIT covers newly authored support work and OFL covers fonts.

[Single-project tools](../artwork/brands/tools/README.md) extend the frozen
collection without rewriting its 54 kits or historical metadata. Both commands
refuse committed versions. Exact `source-*.json` records stay unformatted and
are checksum-checked. The shared asset generator supports a null predecessor;
the site and static study show a single first-identity specimen.

Publish and retrieve materials with the [R2 skill](../.agents/skills/hexly-r2-media/SKILL.md):

```sh
bun run assets:r2 -- plan --project pi-agent-policy --scope all
bun run assets:r2 -- publish --project pi-agent-policy --scope all --upload
bun run assets:r2 -- verify --project pi-agent-policy --scope all
bun run assets:r2 -- url /brands/pi-agent-policy/v1.0.0/logo.png
```

Scope `all` preserves the original rejected/unselected source studies as well as
approved public exports. Rasters remain outside Git. `docs/assets/publication.jsonl`
contains real upload and byte-verification receipts. Product-source image copies
follow that repository's own conventions.
