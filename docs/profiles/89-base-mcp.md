## Project goal

Register entity CRUD tools and compose OAuth and HTTP integration helpers for MCP servers. Consumers own authentication, storage and transport hosting; this is not a standalone deployed MCP service.

为 MCP 服务注册实体 CRUD 工具并组合 OAuth、HTTP 集成辅助。消费方负责认证、存储与传输服务，本项目不是独立部署的 MCP 服务。
