## Project goal

Let external CLI bots dispatch tasks to local Antigravity conversations, wait on events and collect structured results and artifacts, with a protocol modelled on herdr-core.

让外部 CLI 机器人向本机 Antigravity 会话派发任务、按事件等待并回收结构化结果与产物，协议设计对齐 herdr-core。
