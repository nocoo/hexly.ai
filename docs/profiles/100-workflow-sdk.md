## Project goal

Provide a TypeScript Agent and Workflow SDK aligned with the google-antigravity Python SDK, offering both an isolated uv stdio NDJSON bridge to the Antigravity localharness and a pure-TS Vercel AI SDK execution kernel behind one typed API.

提供与 google-antigravity Python SDK 对齐的 TypeScript 智能体与工作流开发套件，以统一强类型接口封装 Antigravity uv stdio NDJSON 桥接与纯 TypeScript Vercel AI SDK 双执行内核。
