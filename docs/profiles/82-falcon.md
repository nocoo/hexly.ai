## Project goal

A native macOS application in development for routing local Agent requests to Jev and inspecting their decisions. Its design connects each source, request context, returned answer and usage record, with seven-day local retention. The preserved local source includes the Swift application foundation; no public application release is claimed.

正在开发的 macOS 原生应用，用于转发本机 Agent 的 Jev 请求并查看决策。设计将调用来源、请求上下文、返回答案与用量关联起来，在本机保留七天记录。已保存的本地源码包含 Swift 应用基础，尚不宣称已有公开应用版本。
