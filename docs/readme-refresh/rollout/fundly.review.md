## 复核依据

- 全文核对双语说明、索引、三个 manifests、Bun API 实际入口、Vite / Docker / Railway 配置、认证代码、采集编排、4433 与多因子评分、临时数据库 API 测试。
- 当前服务由 Bun / Hono 直接运行，SQLite 放在本机或 Railway 持久卷。旧 apps/worker 的目录名和残留 D1 代码没有被当作生产技术栈。
- 4433 与多因子评分已经实现；基金比较、ETF / 股票查询和详情、宏观页面均有当前路由及指标支持。通用回测、交易和 Discord 推送未写成已实现功能。
- 数据目录、历史行情、财报与指标分别采集，网页只读已落库行情；refresh:select 实际先更新全池，再计算排名 / 风险 / 选基指标。常驻采集需要显式 --watch。
- 行情连接只读，但 Backy 的配置、创建备份和恢复 API 会写入或替换数据；文稿没有把整个应用描述为只读。
- Google OAuth / PKCE 和 jose 会话、默认必需认证、缺配置返回 503、空 allowlist 放行已登录账号与源码相符。本地 HTTPS 回调需自行准备，不能把复制环境模板写成开箱即用。
- Bun 各包依赖、初始化空数据库、三个类型检查入口和测试命令真实存在。API 集成是 Hono app.request 配合临时 SQLite，未冒充真实浏览器或远程端到端测试。
- 保留来源说明、GoFundBot / AKShare 致谢与 MIT。主代理仅润色中文一句话介绍与目标字段，没有扩充功能承诺。
