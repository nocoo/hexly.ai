## 复核依据

- 全文核对中文与英文，读取 manifest、启动入口、Explorer 状态转换、A* 寻路、玩具注册表、相机与 UI 控件、足迹存取、音频、构建和 CI 配置。
- 八类玩具、城堡与木马的下一站排队、暂停时选择玩具会恢复活动，均与实现一致。没有教育、治疗或远程模型效果承诺。
- 仅当天足迹写入 localStorage，载入与继续访问时按本地日期过滤；角色位置、进行中动作和历史日期不持久化。减少动态效果时初始暂停，音乐默认静音。
- 单指旋转、双指缩放、跟随、自动旋转、日夜与实际快捷键已核对，缩放没有写成不存在的键盘快捷键。
- 纯 TypeScript / DOM / Three.js 静态应用，Workers 只托管静态资源；Worker 名称 gagaya 与需要另行提供 Wrangler 的部署前提准确。
- 浏览器脚本自动启动 loopback Vite，诊断接口仅在开发环境提供；自定义服务地址须使用开发服务，外部服务分支不执行热更新检查。当前 CI 只构建及类型检查。
