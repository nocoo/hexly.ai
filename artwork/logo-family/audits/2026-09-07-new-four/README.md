# Four newly catalogued identities

Local generation batch for Clip, Fundly, DreamRO and Meowth. The [direction records](directions.json) describe three fragmented animal portraits and one physical game emblem. The [exact owner instruction](authorization.json) delegates raw-image acceptance, keeps publication local, and leaves site verification to the owner.

The original identities are preserved in the catalogue and `public/logos/originals/`. Every completed study receives its own static comparison and `/logos/<project>` path. This record will be updated with actual generation and finishing outcomes; it does not claim completion before those files exist.
