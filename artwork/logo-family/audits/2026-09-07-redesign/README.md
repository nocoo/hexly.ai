# Five animal redesigns — verification

The owner delegated raw-image selection and complete source adoption. These records distinguish drawing checks, source consumers, local site review, remote source publication, and deployment.

- `artwork-verification.json`: native drawing, alpha, safe margins and historical finishing evidence.
- `source-assets.json`: exact source masters, README targets, platform icons and small transparent consumers.
- `source-sidebar-review.json`: actual source sidebar components and CSS with explicit session/router fixtures.
- `native-ui.json`: actual native view renders, fixture boundaries and renderer limitations. Harnesses and intermediate captures remain archived.
- `browser-review.json`: separate Vite and static pages, four language/theme/viewport arrangements, all display modes, downloads, palettes, keyboard navigation and Refined ordering.
- `source-publication.json`: exact remote revisions, CI/deployment jobs, and public image checksums where a public website exists.

Screenshots are verification artifacts. The fifteen projects retain individual `/logos/<project>` and static review pages. No combined review page was added, and no review window was opened for the owner.
