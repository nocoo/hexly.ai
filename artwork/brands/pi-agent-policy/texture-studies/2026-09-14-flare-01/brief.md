# Pi Agent Policy — pressed service mat

Local decorative-background study; not an identity replacement or a published
brand package. Parent campaign archive: 1.0.2. The approved graphite reset
instrument, original colors, Wordmark, icons and existing exports stay unchanged.

## Owner direction

On 2026-09-14 the owner requested another texture version using the updated
Workflow GPT Image skill: Sunburst for Logos, Flare for secondary decoration.
The earlier request asks for a visible, product-related surface analogy rather
than an almost invisible line drawing. This study uses
`gpt-image-2.5-flare` explicitly; it is not a Sunburst run or a hand-drawn SVG.

## Product and surface

Pi Agent Policy provides declarative native-tool rules, interception and one
shared repair allowance per original user input. Evidence is recorded in
`docs/sources/pi-agent-policy-2026-09-14.json` and the parent 1.0.2 recipe.
The approved Logo is a physical reset instrument. Its supporting surface is an
instrument service mat: pressed locating squares, contact seats and one returning
groove. This is a material analogy, not an electrical specification, live status
indicator or security-isolation claim.

The new direction gives the surface shallow, believable physical relief, a
fine matte tooth and readable broad markings. It should feel like a working
material rather than a vector circuit diagram. A sparse terracotta inlay relates
to the approved control and Hexly's red-point motif. No animals, new Logos,
lettering or decorative rainbow components.

## Generation boundary

- Use the actual Workflow `agi-image-generation/scripts/generate.py` helper,
  revision `cd22362da862248bfd6fe3028630f532a135b322`, through Azure OpenAI
  `/openai/v1/images/generations`, with Flare selected explicitly.
- One native 1024 × 1024 PNG for each of the light and dark treatments. Each
  treatment is its own model request with a complete exact prompt. No reference
  image is sent; the approved Logo is a read-only human/agent design reference.
- Light tokens: paper `#f0f0e9`, ink `#30372e`, accent `#bf5c3c`.
  Dark tokens: page `#1e2824`, surface `#27332c`, ink `#e6e9dc`, accent `#e79670`.
  Source: `src/styles/base.css`. Prompt colors are targets, not claims that every
  generated pixel equals a token.
- Request a repeatable, full-bleed material tile directly. Preserve returned
  dimensions and bytes; no cropping, upscaling, tracing or synthetic SVG.
  Tileability is requested, not yet validated or promised.
- Preserve prompt, sanitized request/response, request ID and usage when returned,
  actual native PNG dimensions and SHA-256. Never archive credentials or headers
  containing credentials. No automatic paid retries or model substitution.
- Keep all work under this study directory, outside `public/`. Show untouched
  raw images promptly. Exact-byte raw review precedes production derivatives,
  catalogue integration, R2 publication or release. Previous studies stay intact.
